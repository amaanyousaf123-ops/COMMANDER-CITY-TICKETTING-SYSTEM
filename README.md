# COMMANDER-CITY-TICKETTING-SYSTEM

Mobile Shuttle Ticketing System for Housing Society Express Shuttle Service between **CDR City** and **Karachi**.

## 🚀 Features
- **Mobile-First App**: Optimized interface for booking tickets on mobile phones.
- **Route Options**: CDR City ➔ Karachi & Karachi ➔ CDR City.
- **Traveler Categories**: Residents (PKR 250 with NOC), Visitors/Guests (PKR 500), Employees (PKR 250), Monthly Pass Holders (FREE).
- **EasyPaisa Integration**: Online EasyPaisa payment checkout modal.
- **Digital Boarding Pass**: High-density QR code pass generation.
- **Conductor Portal**: Mobile QR scanner and ticket verification check-in.
- **Admin Dashboard**: Society passenger analytics & CSV manifest export.

## 🛠 Setup & Run
```bash
npm install
npm run dev
```
